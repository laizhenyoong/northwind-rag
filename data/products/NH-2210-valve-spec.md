# NH-2210 Directional Control Valve

4/3-way solenoid operated directional control valve, wet-pin design,
subplate mounted.

## 1. Performance Data

| Parameter | Value |
|---|---|
| Maximum flow | 80 L/min |
| Maximum operating pressure (ports P, A, B) | 250 bar |
| Maximum tank port pressure | 160 bar |
| Switching time, energise | 45 ms |
| Switching time, de-energise | 30 ms |
| Maximum switching frequency | 2 Hz |

## 2. Electrical Data

| Parameter | Value |
|---|---|
| Nominal coil voltage | **24 V DC** |
| Coil power | 30 W |
| Voltage tolerance | ±10% |
| Duty cycle | 100% ED |
| Protection class | IP65 with mating connector fitted |
| Connector | DIN EN 175301-803 form A |

> A 12 V DC coil variant is **not** offered in this series. Applying 12 V
> results in incomplete spool shift; applying 48 V will burn the coil
> within minutes. Coil voltage must be confirmed against the order code
> before commissioning.

## 3. Spool Options

| Code | Centre condition |
|---|---|
| E | Closed centre, all ports blocked |
| F | Float centre, A and B to tank |
| G | Open centre, P to tank |
| J | P blocked, A and B to tank via orifice |

Spool code appears as the fourth element of the order code.

## 4. Physical Data

| Parameter | Value |
|---|---|
| Weight | 6.2 kg |
| Interface | ISO 4401-05-04-0-05 (NG10) |
| Body material | Cast iron GJL-250 |
| Mounting bolt torque | 35 Nm, M10 grade 10.9 |
| Fluid temperature | −20 °C to +70 °C |
| Seal material | Nitrile (NBR) standard, FKM on request |

## 5. Compatibility

- Mates directly with the **NH-8840** pump.
- Requires adapter kit **ADK-221-M** when used with the **NH-8840-X**
  marine pump.
- Supersedes the discontinued NH-1150 valve. The NH-1150 subplate is not
  compatible; a new subplate is required when retrofitting.

## 6. Service

No scheduled service. Coil is field replaceable. Spool assembly is not
serviceable in the field and must be returned to Shah Alam or the Pasir
Gudang service centre.

## 7. Ordering

Base list price RM 3,150. Standard lead time 3 weeks.

Order code format: `NH-2210-<voltage>-<spool>-<seal>`, for example
`NH-2210-24-E-N`.
