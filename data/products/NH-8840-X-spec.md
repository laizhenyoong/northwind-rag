# NH-8840-X Marine Axial Piston Pump

Marine-qualified variant of the NH-8840, for deck machinery, steering gear
and offshore service. Bronze-alloy housing with salt-spray qualified
finish.

> **Do not confuse with the NH-8840.** The two share displacement and
> flow but differ in pressure rating, seal material, permitted speed and
> service regime. They are not interchangeable in marine service.

## 1. Performance Data

| Parameter | Value |
|---|---|
| Maximum flow | 145 L/min |
| Maximum continuous pressure | 350 bar |
| Peak pressure (intermittent, 10 s) | 380 bar |
| Displacement | 71 cc/rev |
| Speed range | 600 – 2200 rpm |
| Volumetric efficiency at rated load | 93% |
| Overall efficiency at rated load | 87% |

## 2. Physical Data

| Parameter | Value |
|---|---|
| Dry weight | 41 kg |
| Housing material | Aluminium bronze CuAl10Ni5Fe4 |
| Mounting | SAE C, 4-bolt flange |
| Shaft | 32 mm splined, SAE C 14-tooth |
| Pressure port | SAE J518 Code 62, 1 1/4 in |
| Suction port | SAE J518 Code 61, 2 in |
| Case drain | 3/4 in BSPP |
| Finish | Epoxy, salt-spray tested ISO 9227 for 720 hours |

## 3. Fluid and Environment

| Parameter | Value |
|---|---|
| Fluid type | Mineral oil ISO 11158 HM, or biodegradable HEES |
| Viscosity range | 12 – 80 cSt |
| Fluid temperature | −30 °C to +90 °C |
| Cleanliness requirement | ISO 4406 17/15/12 or better |
| Seal material | Fluoroelastomer (FKM / Viton) |
| Filtration | 6 µm nominal on return line |

## 4. Marine Service Requirement

**Critical:** In seawater-exposed or splash-zone service, the pump
housing and shaft seal area must be **freshwater flushed every 500
operating hours**. Failure to observe the flushing interval voids the
warranty on the shaft seal assembly and is the leading cause of field
seal failure on this model.

Flushing procedure is given in service bulletin SB-2024-11.

## 5. Acoustic

Sound pressure level 76 dB(A) at 1 m, measured at 1500 rpm and 250 bar
per ISO 4412-1.

## 6. Certification

Type approval **DNV-TA-4471-B**, issued 2022-11-04, renewed 2025-11-04,
next renewal due 2028-11-04. Certificate covers steering gear and deck
machinery duty.

## 7. Interface Compatibility

The NH-8840-X does **not** mate directly with the NH-2210 directional
control valve. Adapter kit **ADK-221-M** is mandatory, owing to the
different case-drain routing on the bronze housing.

## 8. Service Intervals

| Task | Interval |
|---|---|
| Freshwater flush | 500 operating hours |
| Fluid sample and analysis | 750 operating hours |
| Return filter element | 1,500 operating hours |
| Seal inspection | 3,000 operating hours |
| Overhaul | 10,000 operating hours |
