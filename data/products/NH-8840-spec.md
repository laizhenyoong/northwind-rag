# NH-8840 Axial Piston Pump

Variable displacement axial piston pump for industrial hydraulic power
units. General-purpose land-based service.

## 1. Performance Data

| Parameter | Value |
|---|---|
| Maximum flow | 145 L/min |
| Maximum continuous pressure | 320 bar |
| Peak pressure (intermittent, 10 s) | 350 bar |
| Displacement | 71 cc/rev |
| Speed range | 600 – 2400 rpm |
| Volumetric efficiency at rated load | 94% |
| Overall efficiency at rated load | 88% |

## 2. Physical Data

| Parameter | Value |
|---|---|
| Dry weight | 38 kg |
| Mounting | SAE C, 4-bolt flange |
| Shaft | 32 mm splined, SAE C 14-tooth |
| Pressure port | SAE J518 Code 62, 1 1/4 in |
| Suction port | SAE J518 Code 61, 2 in |
| Case drain | 3/4 in BSPP |
| Paint finish | RAL 5010 polyurethane, 60 µm |

## 3. Fluid and Environment

| Parameter | Value |
|---|---|
| Fluid type | Mineral oil to ISO 11158 HM |
| Viscosity range | 12 – 80 cSt |
| Optimum viscosity | 25 – 45 cSt |
| Fluid temperature | −20 °C to +80 °C |
| Cleanliness requirement | ISO 4406 18/16/13 or better |
| Seal material | Nitrile (NBR) |
| Filtration | 10 µm nominal on return line |

Operation outside the stated viscosity range is the single most common
cause of premature wear. Cold starts below 12 cSt equivalent require the
warm-up sequence in the installation manual.

## 4. Acoustic

Sound pressure level 74 dB(A) at 1 m, measured at 1500 rpm and 250 bar
per ISO 4412-1.

## 5. Interface Compatibility

The NH-8840 mates directly with the NH-2210 directional control valve. No
adapter is required.

## 6. Service Intervals

| Task | Interval |
|---|---|
| Fluid sample and analysis | 1,000 operating hours |
| Return filter element | 2,000 operating hours |
| Seal inspection | 4,000 operating hours |
| Overhaul | 12,000 operating hours |

## 7. Ordering

Base list price RM 12,400. Standard lead time 4 weeks ex Shah Alam.

Order code format: `NH-8840-<seal>-<shaft>`, for example `NH-8840-N-S` for
nitrile seals and splined shaft.

## 8. Notes

The NH-8840 replaced the discontinued NH-6600 in 2023. It is **not**
approved for seawater or marine deck service; use the NH-8840-X for those
applications.
